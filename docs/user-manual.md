# 青记（Qing Notepad）功能手册

青记是一款面向 Windows 的桌面记事应用：Markdown 笔记、待办清单、自由画布、便签与磁贴、知识图谱、插件扩展，本地功能免登录即可使用，另有可多人协作的在线工作台。本文是软件内「帮助 → 功能手册」的正文，也是 AI 助手「小青」回答使用问题时的检索来源。

## 界面布局

窗口从左到右分四个区：

- **活动栏**：最左边的图标栏，依次是「记事」「待办」「知识图谱」「在线工作台」「画布」「插件」，底部是「设置」、侧栏折叠与窗口置顶。
- **侧边栏**：随视图显示笔记树、清单列表、图谱筛选、工作台成员、画布列表或插件分组。可拖动分隔条调宽，也可折叠。
- **内容区**：顶部是标签页栏，可同时打开多篇笔记。
- **标题栏**：左侧是应用图标和「帮助」菜单，中间是标题，右侧依次是「公告」喇叭、更新徽标（只在有新版本时出现）、头像和窗口控制按钮。帮助菜单里是功能手册、常见问题、快捷键一览、画布使用说明、检查更新、更新日志、报告问题、设置和关于；头像弹窗里是登录状态（登录 / 退出登录）和「退出软件」。

标题栏最顶部那条 8 像素高的边缘，双击可以把窗口**纵向铺满**屏幕：宽度不变、高度撑满工作区，再双击一次还原。标题栏其余位置双击仍是最大化 / 还原。

## 记事：Markdown 编辑

### 两种视图

切换有三个入口：编辑器「视图」菜单里的「实时渲染 / 源码」、底栏左侧的源码按钮、`Ctrl+/`。

- **实时渲染**（默认）：边写边看排版。`**粗体**`、`*斜体*`、`` `代码` ``、`[文本](链接)`、`~~删除线~~` 的标记在光标离开后就地隐藏，只留内容与样式；标题按 h1–h6 分级字号，引用带左侧竖线，代码块有底纹，分隔线与列表符号自动对齐。
- **源码**：直接编辑原始 Markdown 文本，所有标记都可见。

光标停在某一段里时，**这一段会自动回退成源码**，方便你改标记本身；光标移开立刻恢复排版。不需要为了改一行标记去切视图。

实时渲染下还可以直接用输入规则写格式，按键即生效：

- 行首输入 `#` 加空格得到标题，`>` 得到引用，`-` 或 `1.` 得到列表；三个反引号或 `$$` 后面回车会自动补齐闭合围栏，并把光标留在中间那行；`---` 单独成行后回车变成分隔线。
- 列表里回车自动续写下一项，空项上回车退出列表；`Tab` / `Shift+Tab` 调整列表层级。
- `Ctrl+B` / `Ctrl+I` 直接包裹粗体与斜体；`Ctrl+Z` 一次撤销整条规则，不会留下半截标记。
- 点击任务前面的方框即可勾选 / 取消。
- 这些规则可在设置里逐条关闭。

**表格**按语法树逐格渲染，单元格里可以继续写行内标记；光标进入表格时整块回退成源码，方便改列宽与对齐。**代码块**接入 highlight.js 的 14 门语言，在开头标注语言名即可高亮，显示为圆角卡片。

中文输入法组字期间不会重排排版，候选框落下后一次性补算，拼音阶段不会跳动。

> 云端编辑器（在线工作台里的文档）仍是「源码 / 预览 / 分屏」三档，与本地笔记不同。

### 保存

- 内容**自动保存**，间隔在设置 → 基础里调（10 秒 / 30 秒 / 1 分钟，也可关闭）。
- 按 `Ctrl+S` 立即保存；切换或关闭笔记时也会自动存好，不会丢。

### 独立窗口

- 编辑器工具栏的窗口图标，或「文件 → 在独立窗口中打开」，把当前笔记放进一个单独窗口；同一篇笔记只会开一个窗口，再点会切回已开的那个。
- 独立窗口不是简化版：顶部是应用图标 + 笔记标题 + 窗口按钮，下面是「文件 / 编辑 / 段落 / 格式 / 视图」菜单、正文、目录列和完整底栏（目录 / 源码 / 更新时间 / 保存状态 / 行词字字符）。
- 编辑会自动保存，并与主窗口双向同步；如果两边都有未保存的修改，各自先保留自己的内容，不弹窗打断。
- 右侧「返回主软件」会先保存，再回到主窗口并关掉独立窗口。

### 从资源管理器打开 .md

- 安装版会把「Qing Notepad」写进 `.md` / `.markdown` 的右键「打开方式」（Windows 11 在「显示更多选项」里），**不会**改掉你原来的默认程序；重装或升级不需要先卸载，也不会留下重复项。
- 打开的文件先以草稿形式出现在独立窗口里；标题旁的「外部文件 · 未入库」表示它还没进笔记库。编辑自动存草稿，直接关窗口也不会丢。
- 点「返回主软件」才把它写进笔记库的「未分类笔记」；同一个文件重复打开仍指向同一篇笔记，不会重复添加。
- 如果这个文件本来就在笔记库里，打开的是那篇笔记本身，不会复制一份。

### 图片

把图片**粘贴或拖进**编辑器即可，图片随笔记自动保存并插入引用。预览支持本地附件、本地文件路径和网络图片。

### 导入与导出

- **导入**：侧边栏笔记树顶部点「导入文件」（向上箭头图标），选 `.md`、`.markdown`、`.txt` 文件，导入后是一篇新笔记；导入失败会弹提示并说明原因。
- **导出**：点笔记工具栏上的「导出文件」（向下箭头图标），或右键笔记标签页 →「导出文件」，可存为 Markdown、纯文本、Word（.docx）或 PDF。

### 整理笔记

- **文件夹**：笔记树里可新建、重命名、删除文件夹；右键笔记选「移到文件夹」换位置。
- **标签页**：单击笔记开预览标签（标题是斜体），双击转正式标签，标签可固定；关闭标签用标签上的 `×` 或 `Ctrl+W`。
- **搜索**：侧边栏搜索框按标题和正文过滤笔记，可叠加文件夹、标签筛选。
- **标签筛选**：侧边栏下方列出笔记的标签，点一下只看该标签的笔记。
- **回收站**：删掉的笔记进回收站，可恢复或彻底删除；保留时长（7 / 30 / 90 天、永久或关闭）在设置里调。

## 待办清单

- 可建**多个清单**，各清单任务互不相通。清单可重命名、置顶、拖动排序。
- 任务可设**低 / 中 / 高**优先级和**截止日期**，支持勾选完成、行内编辑、拖拽排序，按状态或优先级筛选。
- 任务可拆成**子任务**，勾选父任务会连带完成子任务。
- 完成的任务自动沉底。删清单会连任务一起删掉，且不能撤销。

## 自由画布

- 画布上可放**图片和多行文字**，支持框选、拖动、缩放、画笔涂鸦。
- 可导出 **PNG、JPEG、SVG** 图片，也可点「创建画布磁贴」把画布钉成桌面小窗。
- 可把笔记或文件夹作为只读引用节点放进画布，双击回到源笔记；连线支持贝塞尔曲线。
- 画布是本地功能，**不参与**在线工作台协作。

## 便签与磁贴

- **便签**：置顶的**可编辑**小窗，放桌面随手记。打开一篇笔记，点工具栏的图钉按钮（界面上叫「钉住磁贴」）即可；关掉小窗不影响笔记。
- **磁贴**：**只读**的笔记小窗，把资料钉在屏幕一角看；渲染与主编辑器同一套，不支持编辑。画布也有磁贴，在画布工具栏点「创建画布磁贴」。

## 知识图谱

- **资料库**：把任意本地文件夹添加为知识库，只读扫描——不复制、不修改、不移位；移除资料库只解除引用，不动磁盘上的文件。
- **图谱视图**：本应用笔记与资料库里的 `.md` / `.markdown` / `.txt` 在同一张图里渲染，支持 `[[wiki 链接]]` 与 Markdown 链接。
- **断链**：指向不存在笔记的链接显示为断链节点；命中多篇同名笔记时提示改写路径。
- **节点详情**：选中节点可看标题、路径与反链，并直接「在编辑器中打开」；本应用笔记支持就地预览。
- **筛选**：可按标签筛选、只看孤立节点、只看断链，以及按标题或路径搜索。
- **索引**：首次打开扫描文件并建索引，之后走缓存；面板显示上次扫描时间、节点数与边数。

## 插件扩展

- 扩展页分「已安装 / 可用」两组，搜索覆盖名称、描述与作者；支持 `.qnp` 包与带清单的文件夹两种安装方式。
- 安装前逐条确认权限：权限码分属笔记、待办、剪贴板、编辑器、画布与 AI 六组，未授予的调用直接拒绝，不会降级执行。
- 插件只在命令面板（`Ctrl+Shift+P`）里追加命令，不改动界面；命令与内置命令同列可搜。插件也能注册自己的侧边栏视图。
- 插件代码在独立 Worker 中运行，拿不到 `window`、`document` 与系统能力，也没有联网能力。
- 详情页可停用、卸载或回滚到上一版本；卸载会收回已授予权限。
- 宿主连续崩溃会自动切回内置模式，失败原因显示在页头，详情页保留最近 100 条错误日志。

## AI 助手「小青」

- **对话**：右侧栏 AI 面板，顶部可在「小青（本地）」与多个云端模型之间切换；云端模型支持自定义 OpenAI 兼容端点，选择会被记住。
- **本地检索**：小青全程离线作答，索引覆盖功能手册、常见问答、笔记、便签、待办与画布文本，回收站不参与检索，不联网也不消耗额度。
- **云端回答**：以检索到的本地内容为上下文生成回答，并标注来源；没配接口时直接给出检索到的原文。
- **选区动作**：在笔记里选中一段文字，右侧栏进入选区动作，可选润色、改写、续写、摘要、翻译、转待办六种。润色 / 改写 / 续写 / 翻译先给前后对比，点「应用」才写入；摘要与转待办只产出结果卡，不覆盖原文。
- **修改权限**：输入栏模型选择右侧的开关，两档——「仅助手」（默认，只回答、不改笔记）与「完全开放」（AI 直接改笔记正文与标题）。每次写入前自动存快照，可在该条回答下点「撤销此次修改」回退。
- **思考强度**：在输入栏的模型按钮上展开，「关闭 / 低（默认）/ 高」三档；思考内容按输出计费，与正文共享输出长度。选中「小青」时不可用。
- **密钥**：API Key 经 Windows 系统加密后只存本机，不写入配置文件，也不上传。

## 在线工作台与实时协作

在线工作台需要联网并登录；未配置在线服务时，本地功能照常使用。

- **账号**：邮箱注册、登录、退出、改密码，昵称与头像管理。
- **工作台**：自己创建，或用**邀请码**加入别人的工作台，并设置新成员默认角色。
- **概览页**：进入工作台先看概览，集中展示文档与成员、最近文档与快捷入口。
- **协作**：文档多人实时编辑，能看到在线成员，框选内容可高亮给别人看；成员变动、被移出会实时提醒。
- 断网时的修改先存本机，恢复网络和登录后自动同步。

## 设置

活动栏底部点「设置」，分七节：

- **基础**：自动保存间隔、回收站保留时长、编辑器字体、全局快捷键。
- **主题**：深色、蓝调、忧郁黄、清新绿四套预设，可自定义配色和背景图（JPG / PNG / WebP），最多存 5 套自定义预设。
- **语言**：中文 / English 即时切换。
- **存储**：把整个数据目录迁移到任意磁盘，迁移前校验写入权限。
- **AI 设置**：添加接口、填 Key、点「搜索模型」拉取该服务的模型列表，勾选后才会出现在聊天栏。
- **插件**：已安装插件、权限与错误日志。
- **个人**：昵称、头像与账户信息。

「关于」窗口显示版本号、作者、源码、博客、QQ 群和赞助入口；检查更新不在关于窗口里，走「帮助 → 检查更新」。

## 更新与公告

- **检查更新**：「帮助 → 检查更新」是软件内更新，发现新版本后点一下就在软件内下载（约 27 MB）并安装，装完自动重启到新版本；失败会显示原因并可重试。
- **标题栏徽标**：发现新版本时右上角出现更新入口，平时零占位；鼠标悬停可看这一版改了什么。
- **两步安装**：第一次点击只下载，图标变成重启键；第二次点击才重启安装，什么时候打断手上的工作由你决定。
- **签名校验**：安装包做签名校验，签名对不上直接拒绝安装。更新源以 Gitee 为主，连不上时才回落到 GitHub。
- **公告**：标题栏喇叭图标显示公告，未读带红点；登录弹窗左侧同样展示最新通告，可逐条忽略。设置里可关闭联网获取，改用随安装包分发的离线快照。
- 更新说明随发布清单分发，卡片内直接滚动阅读，不必先跳浏览器。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Space` | 显示 / 隐藏主窗口（全局生效） |
| `Ctrl+S` | 保存当前笔记 |
| `Ctrl+1 … 6` | 设为一级到六级标题 |
| `Ctrl+Shift+K` | 插入代码块 |
| `Ctrl+K` | 插入链接 |
| `Ctrl+F` | 查找与替换 |
| `Ctrl+/` | 切换源码 / 实时渲染 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+Shift+0` | 放大 / 缩小 / 重置正文缩放 |
| `Ctrl+Alt+T` | 插入表格 |
| `Ctrl+W` | 关闭当前标签页 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（画布内同样生效） |
| `Ctrl+Shift+P` | 打开命令面板 |

要改全局快捷键：到「设置 → 基础」修改按键，或点「恢复默认」。

点关闭按钮只是**最小化到托盘**；要真正退出，用托盘图标右键 `Quit`，或点头像 →「退出软件」（会二次确认，并在确认前把当前笔记写盘）。

## 数据存储与备份

- 本地内容都存在安装或项目目录下的 `data` 文件夹，应用不会静默改写到用户目录或注册表。指针（一小段路径）存在 `%APPDATA%\com.qing-notepad.app\storage.json`，资料本体始终在你指定的目录。
- `data` 里主要是：`notes/`（笔记与索引）、`todos.json` 与 `todo-lists.json`（待办）、`canvas/`（画布）、`ai/`（对话、加密密钥与快照）、`plugins/`（扩展）、`graph/`（资料库注册表与索引）、`img*/`（图片资源）、`trash/`（回收站）、`external-drafts/`（从资源管理器打开的外部文件草稿）、`settings.json` 与 `ui-state.json`（设置与界面状态）。
- 迁移用「设置 → 存储」：同卷即时完成，跨卷先拷贝并逐项校验再删原文件。
- 备份就是复制整个 `data` 文件夹：笔记、待办、画布、图片、设置都在里面。
- 知识库文件夹本身留在原地，`data/graph/` 只保存注册表与索引，移除资料库不影响磁盘上的文件。
- 在线工作台的内容存在云端（Supabase 与协作服务），不在上述目录中；换电脑登录同一账号即可找回。
