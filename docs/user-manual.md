# 青记（Qing Notepad）功能手册

青记是一款 Windows 桌面记事应用：Markdown 笔记、待办清单、自由画布、便签与磁贴、主题定制，本地功能免登录，另有可多人协作的在线工作台。AI 助手「小青」依据本手册回答使用问题。

## 界面布局

窗口从左到右分四个区：

- **活动栏**：最左边的图标栏，切换「记事」「待办」「画布」「在线工作台」，底部是「设置」。
- **侧边栏**：随视图显示笔记树、清单列表、画布列表或工作台成员。可拖动分隔条调宽，也可折叠。
- **内容区**：顶部是标签页栏，可同时打开多篇笔记。
- **标题栏**：右上角只有三样东西——「帮助」菜单、头像和窗口控制按钮。帮助菜单里是功能手册、常见问题、快捷键一览、画布使用说明、检查更新、报告问题、设置和关于；头像弹窗里是登录状态（登录 / 退出登录）和「退出软件」。

## 记事：Markdown 编辑

### 三种视图

工具栏随时切换：

- **源码**：直接编辑 Markdown 文本。
- **预览**：只看排版效果。
- **分屏**：左边编辑、右边预览，滚动同步。

### 保存

- 内容**自动保存**，间隔在设置里调（10 秒 / 30 秒 / 1 分钟，也可关闭）。
- 按 `Ctrl+S` 立即保存；切换或关闭笔记时也会自动存好，不会丢。

### 独立窗口

- 工具栏的「在独立窗口中打开」（窗口图标）会把当前笔记放进一个单独窗口；同一篇笔记只会开一个窗口，再点会切回已开的那个。
- 独立窗口只有笔记本身：顶部是应用图标 + 笔记标题 + 窗口按钮，下面依次是「文件 / 编辑 / 段落 / 格式 / 视图」菜单、正文和完整底栏（目录 / 源码 / 更新时间 / 保存状态 / 字数统计）。
- 编辑会自动保存，并与主窗口双向同步；如果两边都有未保存的修改，各自先保留自己的内容，不弹窗打断。
- 工具栏右侧的「返回主软件」会先保存，再回到主窗口并关掉独立窗口。

### 从资源管理器打开 .md

- 安装版会把「Qing Notepad」加进 `.md` 的右键「打开方式」（Windows 11 在「显示更多选项」里），**不会**改掉你原来的默认程序。
- 打开的文件先出现在独立窗口里；标题旁的「外部文件 · 未入库」表示它还没进笔记库。编辑会自动存为草稿，直接关窗口也不会丢。
- 点「返回主软件」才会把它加入「未分类笔记」；同一个文件重复打开仍指向同一篇笔记，不会重复添加。
- 如果这个文件原本就是青记笔记库里的 `.md`，打开的是那篇笔记本身，不会复制。

### 图片

把图片**粘贴或拖进**编辑器即可，图片随笔记自动保存并插入引用。预览支持本地图片和网络图片。

### 导入与导出

- **导入**：侧边栏笔记树顶部点「导入文件」（向上箭头图标），选 `.md`、`.markdown`、`.txt` 文件，导入后是一篇新笔记；导入失败会弹提示并说明原因。
- **导出**：点笔记工具栏上的「导出文件」（向下箭头图标），可存为 Markdown、纯文本、Word（.docx）或 PDF。

### 整理笔记

- **文件夹**：笔记树里可新建、重命名、删除文件夹；右键笔记选「移到文件夹」换位置。
- **标签页**：单击笔记开预览标签（标题是斜体），双击转正式标签，标签可固定。
- **搜索**：侧边栏搜索框按标题和正文过滤笔记，可叠加文件夹、标签筛选。
- **标签筛选**：侧边栏下方列出笔记的标签，点一下只看该标签的笔记。
- **回收站**：删掉的笔记进回收站，可恢复或彻底删除；超过保存时间自动清理，时长在设置里调。

## 待办清单

- 可建**多个清单**，各清单任务互不相通。清单可重命名、置顶、拖动排序。
- 任务可设**低 / 中 / 高**优先级和**截止日期**，支持勾选完成、行内编辑、拖拽排序，按状态或优先级筛选。
- 完成的任务自动沉底。删清单会连任务一起删掉，且不能撤销。

## 自由画布

- 画布上可放**图片和多行文字**，支持框选、拖动、缩放、画笔涂鸦。
- 可导出 **PNG、JPEG、SVG** 图片，也可点「创建画布磁贴」把画布钉成桌面小窗。
- 画布是本地功能，**不参与**在线工作台协作。

## 便签与磁贴

- **便签**：置顶的**可编辑**小窗，放桌面随手记。打开一篇笔记，点工具栏的图钉按钮（界面上叫「钉住磁贴」）即可；关掉小窗不影响笔记。
- **磁贴**：**只读**的笔记小窗，把资料钉在屏幕一角看。画布也有磁贴，在画布工具栏点「创建画布磁贴」。

## 在线工作台与实时协作

在线工作台需要联网并登录；未配置在线服务时，本地功能照常使用。

- **账号**：邮箱注册、登录、退出、改密码，昵称与头像管理。
- **工作台**：自己创建，或用**邀请码**加入别人的工作台。
- **协作**：文档多人实时编辑，能看到在线成员，框选内容可高亮给别人看；成员变动、被移出会实时提醒。
- 断网时的修改先存本机，恢复网络和登录后自动同步。

## 个性化设置

活动栏底部点「设置」：

- **主题**：想换主题在这里——深色、蓝调、忧郁黄、清新绿四套预设，可自定义配色和背景图（JPG / PNG / WebP），最多存 5 套自定义预设。
- **语言**：中文 / English 即时切换。
- **全局快捷键**：默认 `Ctrl+Space` 显示 / 隐藏窗口，可改成别的按键。
- **AI 设置**：自己添加 API 接口——填接口地址和 Key，点「搜索模型」拉取该服务的模型列表，勾选要用的模型后才会出现在聊天栏。Key 加密存在本机。
- **关于窗口**：显示版本号、作者、源码、博客、QQ 群和赞助入口；检查更新不在关于窗口里，走标题栏「帮助 → 检查更新」。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+S` | 保存当前笔记 |
| `Ctrl+Space` | 显示 / 隐藏主窗口（全局生效） |

要改快捷键：到「设置 → 快捷键设置」修改按键，或点「恢复默认」。

点关闭按钮只是**最小化到托盘**；要真正退出，用托盘图标右键 `Quit`，或点头像 →「退出软件」（会二次确认）。

## 数据存储与备份

- 本地内容都存在安装目录下的 `data` 文件夹；如果安装目录不可写，会存到 `C:\Users\<用户名>\AppData\Roaming\com.qing-notepad.app\data`。
- 备份就是复制整个 `data` 文件夹：笔记、待办、画布、图片、设置都在里面。
- 在线工作台的内容存在云端，换电脑后登录同一账号即可找回。

## AI 助手「小青」与笔记润色

- **AI 助手「小青」**：右侧栏对话，回答软件使用问题。知识来自本手册与常见问答，检索**全在本机**，不联网、不上传。没配接口时直接给出检索到的原文；配好接口后由你选用的模型组织成完整回答。
- **笔记修改权限**：输入栏模型选择右侧的开关，两档——「仅助手」（默认，只回答、不改笔记）与「完全开放」（AI 直接修改笔记正文与标题，立即生效）。每次修改前自动存快照，在那条回答下点「撤销此次修改」即可回退；开启前会确认一次。小青永远只读，开关只对 API 模型生效。
- **选区动作**：在笔记里选中一段文字，右侧栏会进入选区动作，可选润色、改写、续写、摘要、翻译、转待办六种。润色、改写、续写、翻译先给你看**前后对比**，点「应用」才写入；写入前自动存快照，可一键撤销。摘要和转待办只产出结果卡并支持复制，**不会覆盖**你选中的原文。
- **思考强度**：在输入栏的模型按钮上，鼠标悬停或点击展开——「关闭 / 低（默认）/ 高」三档。关闭更快更省；思考内容按输出计费，并和正文共享同一份输出长度。选中「小青」时这项不可用。
- **管理接口与模型**：模型面板底部的「管理接口与模型」会跳到「设置 → AI 设置」，在那里添加接口、点「搜索模型」、勾选允许使用的模型。聊天栏只列出勾选过的模型。
- 发给你配置的那个接口服务商的只有**选中的段落**或**相关的笔记片段**（每段很短）；开启「完全开放」后，AI 改某篇笔记前会把**这一篇**的内容发出去，其余笔记仍只发片段。
