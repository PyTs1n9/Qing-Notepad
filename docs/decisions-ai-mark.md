# 决策记录：小青徽标（activitybar 入口 + 侧栏头部 + 模型选择器，2026-10-28）

## 背景

activitybar 的 AI 入口是一颗 `Sparkles` 线性图标（20px），与设置、图钉同一套视觉语言，
在 44px 宽的图标列里读不出「小青」这个身份。侧栏头部在 `h-9`（36px）里塞了 28px 头像 +
14px 模型名 + 10px 状态文字两行，行高被压到 `leading-tight`。模型选择器里「小青」一行同样是
Sparkles，与 deepseek / mimo / gpt 的彩色 logo 并列时，唯一没有自己图标的就是它。

## 结论

| 主题 | 决定 | 理由 |
| --- | --- | --- |
| 改动范围 | activitybar 入口 + 侧栏头部 + 模型选择器 + 共用 `AssistantAvatar` | 同一身份的标记不能在不同处不一致；模型选择器是「小青」被具体看见的地方 |
| 视觉形态 | **应用图标里的那本打开的书**，圆形底 + 两页展开 + 中缝 | 用户指定参考 `src-tauri/icons/icon.png`；先做笑脸版被否决（「不要笑脸」） |
| 配色来源 | 固定品牌色（`--color-qing-mark-*`），**不跟主题** | 黄/蓝主题下若跟着变，「青」的身份就没了；与 Slack 头像同一逻辑 |
| 底色取值 | 图标雾霾蓝 `#a8c2ca` **压深**为 `#2c4a57`，书页 `#faf4e6` | 图标自己 32x32 的构建体就是证据：浅底 + 浅纸糊成一团。小尺寸必须反着做明暗 |
| 图形取舍 | 只画书，**不画笔记本底座** | 底座是 32px 下第一个消失的东西，在 20px 只剩噪点 |
| 头部高度 | 保持 `h-9`，状态点内联到模型名右侧，状态文字退到 `title` + `aria-label` | `h-9` 让侧栏 `border-b` 与笔记 tab 条跨窗对齐，是硬约束，不能为舒展而破 |
| 状态色 | `bg-success` / `bg-warning`，去掉硬编码 `bg-green-500` 与 `bg-text-muted/50` | 走 token 才能随主题走；未配 key 用 warning 才有信号，灰点等于没说 |
| 动效 | 仅 hover（`opacity` + `scale`）与打开态（静态外发光），无待机动画 | 常驻动画持续占合成线程；`opacity`/`transform` 是合成友好属性，不用 `filter` |
| 渐变 id | `useId()` 清洗非字母数字字符后拼接 | `:r0:` 里的冒号在 `url(#…)` 中会失效，同页多实例也会撞 id |

## 迭代记录（图形形态，均已离屏渲染核对）

1. **青绿笑脸徽标**（双眼 + 微笑弧）——用户否决：「不要笑脸」。
2. **书，每页上沿各自鼓起**——离屏渲染发现读作「两本竖立的小书并排」，因为贝塞尔控制点让曲线先冲高再回落。
3. **书，外高内低的单调斜线**——读作一本书，但底部 V 太尖像蝴蝶结/心形。
4. **底部 V 收缓**（中缝末端 22.3）——定稿。

20px 下书脊曾是 0.7px，两页焊接成一个亮斑；加粗到 2.2 units、`opacity 0.72` 后可读。
外圈描边从 `0.22` 提到 `0.32`，因为 `#2c4a57` 圆底在 `#1e1f23` 的夜间侧栏上只有 1.74:1。

## 不做

- 不给徽标加常驻呼吸光（性能换不来信息）。
- 不改 `.activity-capsule` 的 accent 配色（页签选中与 AI 打开态共用，单独改色会分裂语义）。
- 不动 `Sparkles` 在「AI 功能」语义处的用法：润色按钮、AI 设置 tab、更新公告、插件权限图标——那些是功能图标，不是小青的身份。
- 不改气泡布局、输入胶囊、模型选择器的结构（属 `decisions-ai-sidebar-redesign.md` 的地盘）。

## 验证

- `npx tsc --noEmit` 通过。
- `npm run verify:ui-polish`：15 条静态审计 + 152 组对比度，no failures。
- 离屏渲染（sharp/librsvg）核对 20/24/28/44px × blue/dark/yellow/green 四主题，书形均成立。
