# 青记（Qing Notepad）常见问题

使用青记时的常见疑问。答案以实际功能为准；没有做的功能会如实说明，不编造。

## Q1｜你是谁？

我是「小青」，青记内置的 AI 助手，回答青记的使用问题。我的知识来自内置《功能手册》与《常见问答》，检索**全在本机**，检索结果不出本机；在「设置 → AI 设置」里添加一个 API 接口（地址 + Key）后回答会更连贯，此时提问与相关片段会发给你配置的那个服务。手册没覆盖的问题我会如实说明。

## Q2｜怎么搜索笔记？能搜正文吗？

能。在记事视图的侧边栏搜索框输入关键词，笔记列表实时过滤，**标题和正文**都算（不区分大小写），还可叠加文件夹、标签筛选。注意它筛的是「哪些笔记匹配」，不是在一篇笔记里跳转定位。

## Q3｜忘记登录密码怎么办？

登录窗口点「**找回密码**」，输入注册邮箱，系统会发一封重置邮件：

1. 点邮件里的「重置密码」按钮，会自动打开青记继续设置新密码；
2. 没反应的话，在邮件里**右键复制「重置密码」按钮的链接**，粘贴到应用里的密码恢复框，点「验证链接并继续」。

链接过期就重新发一封。本地功能不需要账号，忘记密码只影响在线工作台。

## Q4｜怎么建多个待办清单？能改名、删除、置顶吗？

待办视图的侧边栏点「新建清单」即可，各清单任务互不相通。清单可以**重命名、置顶、拖动排序**；删除清单会连同里面的任务一起删掉，**不能撤销**（有二次确认）。

## Q5｜换电脑或重装系统后，笔记怎么搬过去？

搬的是数据文件夹：

1. 先在旧电脑上确认数据目录的位置：默认在青记安装目录下的 `data`；如果用过「设置 → 存储」迁移，就以设置里显示的那一处为准。指针（一小段路径）记在 `%APPDATA%\com.qing-notepad.app\storage.json`，那里**没有**第二份数据，目录不存在时青记会明确报错而不是新建空目录。
2. 整个文件夹复制到新电脑，再在「设置 → 存储」里指向它。

笔记、待办、画布、图片、设置都在这个文件夹里。在线工作台的内容在云端，不跟着文件夹走；新电脑登录同一账号就有。

## Q6｜能开机自动启动吗？

不能，当前版本**没有开机自启动**，设置里也没有开关。需要的话可以在 Windows 的「启动」文件夹里放一个青记快捷方式——这是系统的做法，不算青记的功能。

## Q7｜能同时打开多篇笔记吗？标签页怎么用？

能。内容区顶部是标签页栏：

- **单击**笔记开**预览标签**（标题是斜体），临时看看；
- **双击**转**正式标签**，适合对照着写；
- 标签可以**固定**。

切换或关闭标签时内容自动保存，不会丢。

## Q8｜便签和磁贴有什么区别？

- **便签**：置顶的**可编辑**小窗，放桌面随手记；关掉小窗不影响笔记。
- **磁贴**：**只读**的笔记小窗，把资料钉在屏幕一角看。

一句话：要写用便签，要「钉着看」用磁贴。

## Q9｜删掉的笔记能恢复吗？

能。删掉的笔记先进**回收站**，可「恢复」或「彻底删除」。回收站有**保存时间**，到期自动清理，时长在设置里改；也可以在设置里关掉回收站——关掉后删除就是直接永久删除。

## Q10｜怎么检查更新？

点标题栏「帮助 → 检查更新」。发现新版本后点一下就在软件内下载（约 27 MB）并安装，装完自动重启到新版本，**不用**再去网页下载安装包覆盖安装；失败会显示原因，可以重试。

有新版时标题栏右上角还会出现更新徽标，平时不占位。下载与安装分两步：第一次点击只下载，图标变成重启键，第二次点击才重启安装。安装包做签名校验，签名对不上会拒绝安装。

两点注意：更新包下载后只保存在内存里，重启前退出应用需要重新下载；0.8.0 及以前的版本里没有更新代码，需要手动安装一次，之后每个版本都能在软件内完成。

想看这一版改了什么：「帮助 → 更新日志」可回看本版说明；鼠标悬停在标题栏的更新徽标上，也能直接看到新版本的更新说明——说明随发布清单分发，由安装包之外的清单携带，因此能显示「还没装上」的那一版。

## Q11｜有手机版或 Mac 版吗？

没有。青记目前**只有 Windows 版**。在线工作台的云文档配好后可以用浏览器参与协作，但青记本体只支持 Windows。

## Q12｜笔记能按标签分类吗？怎么给笔记加标签？

侧边栏下方会列出笔记的标签，点标签就**只看该标签的笔记**。不过当前版本**还没有添加标签的入口**，界面上不能给笔记打标签；用**文件夹**分组是目前整理笔记的主要方式。

## Q13｜关闭窗口后程序去哪了？

点关闭只是**最小化到系统托盘**，程序还在后台。要真正退出：托盘图标右键菜单点 `Quit`，或点头像 →「退出软件」（会二次确认）。

## Q14｜不登录能用吗？

能。记事、待办、画布、便签、主题这些**本地功能都不用登录**；只有在线工作台和账号相关功能需要登录。

## Q15｜旧版本的笔记还能打开吗？

能。`.md` 文件可以是标准 Markdown，也可以是旧版本保存的 HTML 格式，打开时会自动转成当前编辑格式。

## Q16｜画布内容会同步到工作台吗？

不会。画布是纯本地功能，只有在线工作台的云文档才会多人同步。

## Q17｜小青回答不出来，或只给原文片段怎么办？

没配接口时，小青只能把检索到的**手册原文**流式给出。到「设置 → AI 设置」添加接口：填接口地址和 Key，点「搜索模型」，勾选要用的模型，之后就有完整回答。小青只答青记的使用问题，超出范围会如实说明。

## Q18｜怎么把笔记导出为 PDF 或 Word？

打开笔记，点笔记工具栏上的「导出文件」（向下箭头图标），在保存对话框里选 **PDF** 或 **Word（.docx）** 格式；也可以存成 Markdown 或纯文本。

## Q19｜AI 能直接修改笔记吗？改错了怎么撤销？

默认不能：助手只回答问题，不动你的笔记。想让 AI 直接改，把输入栏模型选择**右边的权限开关**拨到「完全开放」（开启时会确认一次），它就能修改笔记的正文和标题，改完立即生效。改错了不用慌：每次修改都留有快照，在那条回答下方点「撤销此次修改」，就回退到修改前。拨回「仅助手」随时恢复只读；小青（本地检索）永远只读，开关只对 API 模型生效。

## Q20｜为什么本地笔记没有「预览」「分屏」了？

本地编辑器现在只有「实时渲染」和「源码」两档。实时渲染本身就把排版画出来了，而且光标停在哪一段、那一段就退回源码，所以预览与分屏不再需要。切换入口有三个：「视图」菜单、底栏左侧的源码按钮、`Ctrl+/`。在线工作台里的云文档仍是源码 / 预览 / 分屏三档，与本地不同。

## Q21｜能在资源管理器里用青记打开 .md 吗？

可以。安装版会把「Qing Notepad」写进 `.md` / `.markdown` 的右键「打开方式」（Windows 11 在「显示更多选项」里），**不会**改掉你原来的默认程序，重装或升级也不用先卸载。

打开的外部文件在独立窗口里**直接编辑源文件**，标题旁标「直接编辑源文件」：每次自动保存都写回你双击的那个文件，不在软件内部另存副本。点「返回主软件」才把它加进笔记库的「未分类笔记」，此后源文件仍是正文权威，`notes/` 里的是同步镜像；同一个文件重复打开仍指向同一篇，本来就属于笔记库的文件打开的是原笔记，编辑同样写回源文件，不会复制。文件被其他程序改过时会暂停自动保存并让你二选一（重新加载 / 保留我的修改），只读或无权限也会明确提示。
