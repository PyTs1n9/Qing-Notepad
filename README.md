## 项目简介

QingNotepad 是 Windows 上的轻量桌面工作台，**不登录也能用**：打开就能写，所有本地内容落在一个 `data/` 目录里，复制这个目录就是完整备份，也能在设置里迁移到任意磁盘。

它把「记下来 → 摆清楚 → 找得到」收进同一个窗口：Markdown 实时渲染编辑器负责写，待办清单、自由画布与置顶便签负责摆，知识图谱把本应用笔记和磁盘上任意只读资料库连成一张图（`[[wiki 链接]]`、反链与断链检查都现成）。AI 助手「小青」全程离线，在这些本地内容里检索作答，不联网也不消耗额度；需要生成式回答时，可接自己的 DeepSeek 或任意 OpenAI 兼容端点，回答会标注来源。在线工作台用于跨设备保存与多人实时协作，是**可选项**，不配置服务不影响上述任何本地能力。

编辑器采用**实时渲染**：Markdown 标记在光标离开后隐藏，只留排版结果；光标回到段落里时该段自动退回源码。标题、引用、列表、表格、代码块与任务复选框都按语法树渲染，`Ctrl+/` 可随时切回纯源码视图。

### 为什么值得试试

- **磁盘上的 `.md` 就是那一份**：从资源管理器用 Qing Notepad 打开，编辑的直接是源文件，UTF-8 / UTF-8 BOM / GB18030 与 CRLF / LF 原样保留，同目录临时文件 + 原子替换写入，保存后 git 不会出现整文件 diff，也不会抢走你原有的默认程序。
- **窗口跟着你的手走**：当前笔记可拆成独立窗口（菜单栏、目录列、状态栏一个不少），两个窗口贴边后双击缝隙即可成组联动；便签与磁贴能置顶常驻，应用在后台新建小窗也会直接拿到焦点。
- **AI 先读你的资料，再回答**：小青离线检索功能手册、常见问答、笔记、便签、待办与画布文本；云端模型以检索结果作答并标注来源，API Key 经 Windows 加密后只存本机。选中文字可润色，让 AI 改动笔记前会自动留快照、支持逐条撤销。
- **扩展与外观都可控**：插件代码在独立 Worker 沙箱里运行，拿不到 `window` / `document` 与系统能力，安装前逐条确认权限、命令集中在命令面板；四套预设主题、自定义配色与背景、中英即时切换、应用内更新与数据目录迁移都是现成的。

## 功能特点

### 📚 Markdown 记事本

- 1️⃣ 本地笔记提供「实时渲染」「源码」两档视图：`**粗体**`、`*斜体*`、行内代码、链接、删除线，以及标题 `#`、引用 `>` 的标记在光标离开后隐藏，只留内容与样式；标题分级、引用竖线、代码块底纹与分隔线自动生效，列表符号渲染成 `•` / `◦` / `▪` 与递增序号，任务列表是可点击的复选框
- 2️⃣ 光标所在段落回退为源码，移开即恢复排版；`Ctrl+/` 在实时渲染与源码间切换；底栏新增「纯预览编辑」开关，开启后全文保持渲染态不回退，表格可双击就地编辑（`Tab` / `Enter` / `Esc` 移格与提交），列宽可拖拽、链接可点击跳转
- 3️⃣ 输入规则直接写格式：行首 `#`、`>`、`-`、`1.`、三个反引号、`$$`、`---` 按键即生效，列表回车自动续项，`Tab` / `Shift+Tab` 调整层级，规则可逐条关闭
- 4️⃣ 表格按语法树逐格渲染，单元格可继续写行内标记；代码块接入 highlight.js 的 14 门语言高亮，显示为独立圆角卡片：``` 围栏自动隐藏、右下角悬停浮出语言选择器，块内 `Ctrl+A` 先选中本块代码、再按选全文，粘贴多行代码自动成块；代码字号比正文小一档，注释用正体，语法配色分主题校准对比度
- 5️⃣ 笔记树支持文件夹归类，单击预览、双击固定为标签页，可同时打开多篇笔记；搜索同时匹配标题与正文，可叠加文件夹与标签筛选；标题行新增全局搜索键，内联搜索实时命中标题与正文并高亮片段，未打开过的笔记按需补读正文；「全部展开 / 全部折叠」合并为单一动作式按钮，图标提示下一次点击的行为
- 6️⃣ 支持导入 `.md` / `.markdown` / `.txt`，导出 Markdown、纯文本、Word（.docx）或 PDF
- 7️⃣ 图片粘贴或拖入即存为附件，预览支持本地附件、文件路径与网络图片
- 8️⃣ 按设定间隔自动保存，`Ctrl+S` 立即保存；删除的笔记进入回收站，可恢复或彻底删除
- 9️⃣ 正文默认使用系统无衬线字体栈，中文不再回退到等宽字体；编辑器字体可在设置里更换，行号与折叠槽随字号等比缩放、行号对齐正文基线，正文缩放走 `Ctrl+=` / `Ctrl+-` / `Ctrl+Shift+0`
- 🔟 中文输入法组字期间不重排排版，候选框落下后一次性补算

### 🪟 独立笔记窗口

- 1️⃣ 编辑器工具栏的窗口图标，或「文件 → 在独立窗口中打开」，把当前笔记放进单独窗口；同一篇只开一个，重复点击切回已开的那个
- 2️⃣ 独立窗口复用主窗口的菜单栏、CodeMirror、目录列与完整底栏（目录 / 源码 / 更新时间 / 保存状态 / 行词字字符），不是简化版
- 3️⃣ 与主窗口双向同步保存；两边都有未保存修改时各自保留自己的内容，不弹窗打断
- 4️⃣ 「返回主软件」先保存，再回到主窗口并关掉独立窗口
- 5️⃣ 应用在后台时打开也直接出现在最前并拿到键盘焦点，不会只在任务栏闪一下

### 🧲 窗口贴合

- 1️⃣ 主窗口与独立笔记窗口摆到贴边后，双击两者之间的缝即把两个窗口成组；再双击同一条缝解绑
- 2️⃣ 成组后拖动或缩放任一方，另一方跟着平移；缩放任一方时另一方只移动、不改尺寸
- 3️⃣ 位置按「当前几何 + 成组时记下的偏移」重新计算，拖多久都不累积偏移
- 4️⃣ 双击需落在窗口内、且距靠缝那条边 12px 以内；标题栏最顶部 34px 不参与判断，那里的双击仍是铺满 / 最大化
- 5️⃣ 跨显示器、跨缩放比例、最大化、最小化或关闭任一窗口都会自动解绑；一次只成一组、最多两窗，第三方软件的窗口不在范围内

### 📂 从资源管理器打开 .md

- 1️⃣ 安装版把「Qing Notepad」写进 `.md` / `.markdown` 的右键「打开方式」，**不抢**默认程序，重装或升级不需要先卸载
- 2️⃣ 打开的就是那个文件本身：标题旁标「直接编辑源文件」，每次自动保存都写回你双击的那个文件，不在软件内部另存副本；UTF-8 / UTF-8 BOM / GB18030 与 CRLF / LF 换行原样保留，写入用同目录临时文件 + 原子替换，保存后 git 不会出现整文件 diff
- 3️⃣ 点「返回主软件」才把它加进笔记库的「未分类笔记」，此后源文件仍是正文权威，`notes/` 里的是同步镜像；同一文件重复打开仍指向同一篇，已在库里的文件打开的是原笔记，编辑同样写回源文件
- 4️⃣ 文件被其他程序改过时暂停自动保存，让你选「重新加载源文件」或「保留我的修改」；只读、被移走或无权限时明确提示，不会静默丢改

### 🗓️ 待办清单

- 1️⃣ 支持创建多个任务清单，清单内任务隔离，可重命名、置顶与拖动排序
- 2️⃣ 任务支持低 / 中 / 高三档优先级与截止日期日历选择
- 3️⃣ 任务可拆为子任务，勾选父任务会连带完成其子任务
- 4️⃣ 支持行内编辑与拖拽排序，按状态和优先级筛选，完成的任务自动沉底

### 🎨 自由画布

- 1️⃣ 支持创建多个本地画布，可放置图片与多行文本
- 2️⃣ 支持粘贴、拖放或选择本地图片，并可框选、拖动、缩放与画笔涂鸦
- 3️⃣ 支持将当前画布导出为 PNG、JPEG 或 SVG
- 4️⃣ 可把笔记或文件夹作为只读引用节点放进画布，双击回到源笔记；连线支持贝塞尔曲线
- 5️⃣ 画布内容和图片资源保存在本地，不参与在线工作台的实时协作

### 📌 便签与磁贴

- 1️⃣ 便签是可编辑的置顶小窗，用来随手记录而不打断当前笔记
- 2️⃣ 磁贴是只读小窗，可把笔记或画布钉在屏幕一角常驻查看
- 3️⃣ 关闭小窗不影响原笔记内容，两者相互独立
- 4️⃣ 新建便签与磁贴时应用在后台也会把窗口提到最前并取得焦点，已存在的窗口会从最小化还原

### 🕸️ 知识图谱

- 1️⃣ 把任意本地文件夹添加为「资料库」，只读扫描：不复制、不修改、不移位，移除资料库只解除引用
- 2️⃣ 本应用笔记与资料库中的 `.md` / `.markdown` / `.txt` 在同一张图里渲染，支持 `[[wiki 链接]]` 与 Markdown 链接
- 3️⃣ 指向不存在笔记的链接显示为断链节点，命中多篇同名笔记时提示改写路径
- 4️⃣ 选中节点可查看标题、路径与反链，并直接「在编辑器中打开」；本应用笔记还支持就地预览
- 5️⃣ 支持按标签筛选、「只看孤立节点」「只看断链」，以及按标题或路径搜索
- 6️⃣ 首次打开扫描文件并建立索引，之后走缓存；面板显示上次扫描时间、节点数与边数

### 🤖 AI 助手「小青」

- 1️⃣ 右侧栏 AI 面板，顶部可在「小青（本地）」与「DeepSeek（API）」等多个模型间切换；云端模型支持添加自定义 OpenAI 兼容端点，选择会被记住
- 2️⃣ 小青全程离线作答：索引覆盖功能手册、常见问答、笔记、便签、待办与画布文本，回收站不参与检索，不联网也不消耗额度

- 4️⃣ 选中文字即可润色，内置「润色 / 更简洁 / 更正式 / 更口语化」四种风格并可补充自定义要求，结果先预览、点「应用」才写入
- 5️⃣ 可在对话中让 AI 直接修改笔记；每次写入前自动留存快照，支持按条撤销，修改权限分「仅助手」与「完全开放」两档
- 6️⃣ API Key 经 Windows 系统加密后仅存本机，不写入配置文件，也不上传

## 快速开始

### 下载安装

请前往 [Releases 页面](https://github.com/PyTs1n9/Qing-Notepad/releases/latest) 下载最新版本。

| 系统 | 架构 | 推荐文件 |
| --- | --- | --- |
| Windows | x64 | `QingNotepad_<版本>_x64-setup.exe` |

下载后运行安装包即可使用，首次启动无需登录。安装版会把「Qing Notepad」加入 `.md` 的右键「打开方式」，不改变你原有的默认程序。

普通关闭会将应用隐藏到系统托盘；需要真正退出时，请用托盘菜单的 `Quit`，或点击头像 →「退出软件」（会二次确认）。

### 从源码构建

请先阅读 [README-dev.md](README-dev.md) 了解开发环境、Tauri 构建和发布流程。常用命令如下：

```powershell
npm ci
npm run dev                 # 仅启动 Vite 前端
npm run tauri dev           # 启动完整 Tauri 桌面应用
npm run build               # TypeScript 检查并构建前端
npm run tauri build         # 构建 Windows NSIS 安装包
```

若要本地运行协作服务：

```powershell
npm run collab:dev
```

### 在线工作台部署

在线工作台是可选能力，不配置服务时不影响本地记事、待办、画布和便签。部署时请按 [docs/online-workspace.md](docs/online-workspace.md) 的顺序执行 Supabase 迁移并启动协作服务。

桌面应用需要以下公开环境变量：

```env
VITE_SUPABASE_URL=https://你的项目.supabase.co
VITE_SUPABASE_ANON_KEY=你的 publishable key
VITE_COLLAB_URL=wss://你的协作服务域名
```

协作服务器还需要 `SUPABASE_URL`、`SUPABASE_ANON_KEY` 和仅服务器可见的 `SUPABASE_SERVICE_ROLE_KEY`。`service_role` 密钥不能写入桌面应用、提交到 Git 或放进安装包。

## 数据存储

所有本地内容都保存在安装目录（开发构建为仓库根目录）下的 `data/` 中，应用不会静默改写到用户目录或注册表。数据目录可在「设置 → 存储」中迁移到任意磁盘：同卷迁移即时完成，跨卷迁移会先拷贝并逐项目校验再删除原文件，确保不会丢失资料。迁移指针（仅一小段路径）存放在 `%APPDATA%\com.qing-notepad.app\storage.json`，资料本体始终留在你指定的数据目录。主要内容包括：

```text
data/
├── todos.json              # 待办任务
├── todo-lists.json         # 待办清单和当前清单
├── fonts.json              # 导入字体注册表
├── settings.json           # 主题、语言、背景、快捷键、自动保存、编辑器字体等设置
├── ui-state.json           # 当前打开的标签页
├── app-icon.png            # 自定义应用图标
├── img/                    # 笔记图片附件
├── img-canvas/             # 画布图片资源
├── img-need/               # 头像和应用背景历史
├── img-trash/              # 待清理的图片资源
├── notes/
│   ├── index.json          # 笔记元数据、文件夹与分类索引
│   └── <id>.md             # 笔记正文与外部文件镜像，兼容历史 HTML
├── trash/notes/            # 回收站中的笔记
├── canvas/
│   ├── index.json          # 画布列表
│   └── boards/*.json       # 画布内容
├── ai/
│   ├── chats.json          # AI 对话记录
│   ├── credentials.bin     # 经系统加密的 API Key
│   ├── preferences.json    # 模型与搜索偏好
│   └── snapshots/          # AI 改写前的笔记快照
├── plugins/                # 已安装扩展：包体与授权记录
└── graph/
    ├── vaults.json         # 资料库（只读文件夹）注册表
    └── index/              # 扫描索引与节点坐标缓存
```

知识图谱添加的资料库文件夹本身留在原地，`data/graph/` 只保存注册表与索引缓存，移除资料库不会影响磁盘上的文件。从资源管理器打开的文件正文始终留在原路径，入库后 `notes/` 里的副本只是镜像；删掉镜像不会动源文件。

备份本地内容时复制整个 `data/` 目录即可。在线工作台的数据不在上述本地目录中，而是保存于你配置的 Supabase 和协作服务。

## 常见问题与限制

**支持哪些操作系统？** 目前发行包面向 Windows x64 桌面环境。

**不登录能使用吗？** 可以。记事、待办、画布、便签、主题和本地小青都不需要登录；只有在线工作台与账户功能需要 Supabase，实时编辑还需要可访问的协作服务。

**关闭窗口后程序去哪了？** 普通关闭会隐藏到系统托盘；使用托盘菜单的 Quit 或头像里的「退出软件」才会真正退出。

**为什么本地笔记只有「实时渲染」和「源码」两档？** 实时渲染已经把排版实时呈现出来，原来的「预览」与「分屏」不再需要，云端编辑器仍保留源码 / 预览 / 分屏三档。

**更新会不会重复下载？** 更新包下载后只保存在内存里，重启前退出应用需要重新下载（约 27 MB）；0.8.0 及以前的版本需要手动安装一次才能进入软件内更新。

更多操作细节见 [功能手册](docs/user-manual.md)，其余问答见 [常见问答](docs/user-faq.md)。
